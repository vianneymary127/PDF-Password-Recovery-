Hands-on cybersecurity lab involving the recovery of a password for three protected PDF files using the NetworkWalks Lab environment.
#  PDF Password Recovery – NetworkWalks Lab

##  Project Overview

As part of my cybersecurity learning journey, I was given an assignment involving three password-protected PDF files.

The objective was to determine the password and successfully unlock the protected files.

I completed the challenge using the NetworkWalks Lab environment and successfully recovered the required password.

##  Objective

The main objectives of this exercise were to:

* Investigate password-protected PDF files
* Use a controlled cybersecurity lab environment
* Identify the password required to access the files
* Successfully unlock the protected PDFs
* Document the process and results

##  Tools & Environment

* NetworkWalks Lab
* Kali Linux
* Password-protected PDF files
* Linux-based cybersecurity tools

##  Process

### 1. Identify the Protected Files

I was provided with three PDF files that were password protected.

### 2. Access the NetworkWalks Lab

I used the NetworkWalks Lab environment to work on the challenge in an authorized learning environment.

### 3. Investigate the Files

I followed the lab instructions and used the available tools to investigate the protected PDFs and determine the required password.

### 4. Recover the Password

After completing the required steps in the lab, I successfully obtained the password.

### 5. Unlock the PDFs

I entered the recovered password and successfully unlocked all three PDF files.

## Result

All three password-protected PDF files were successfully unlocked.

This exercise gave me practical experience with:

* File investigation
* Password-protection concepts
* Linux-based cybersecurity tools
* Troubleshooting
* Problem-solving

##  What I Learned

This exercise helped me understand how cybersecurity concepts can be applied in a practical lab environment.

It also improved my confidence in using Linux tools and following a structured approach when solving cybersecurity challenges.
